# 🩸 AI Blood Report Sample Analyzer

An AI-driven diagnostic application built with Python, Streamlit, and Google Gemini API.

## Features
- **Email OTP Login**: Generates dynamic passwordless login passcodes.
- **Report Parsing**: Supports uploading PDF reports or pasting raw test values.
- **Disease & Normal Detection**: Identifies healthy levels or flags specific abnormal metrics.
- **Follow-up Medical Test Advice**: Lists supplementary clinical tests needed.
- **Dietary Recommendations**: Personalised Veg, Non-Veg, and general diet plans.
- **Theme Switcher**: Supports Streamlit's native Light and Dark theme toggling.
